# Agri-Slot Visual Design System (DESIGN.md)

## 1. Color Palette & Dark Mode Strategy
- **Background Core**: `#0A120C` (Midnight Forest Deep Black-Green)
- **Surface Elevation 1**: `#122217` (Dark Pine Glassmorphism)
- **Surface Elevation 2**: `#1A2F21` (Card Container Dark Emerald)
- **Primary Accent**: `#22C55E` (Vibrant Agriculture Green)
- **Secondary Accent**: `#10B981` (Bright Emerald Mint)
- **Highlight Warmth**: `#F59E0B` (Harvest Amber) & `#F97316` (Sunset Orange)
- **Text Primary**: `#F9FAFB` (High Contrast Clean White)
- **Text Muted**: `#9CA3AF` (Cool Slate Gray)
- **Borders & Dividers**: `rgba(34, 197, 94, 0.18)`

## 2. Typography
- **Primary Font**: `'Outfit', 'Inter', -apple-system, sans-serif`
- **Headings**: Semi-bold to Bold (600-700), clean line spacing, tracked tightness
- **Multilingual Support**: Compatible with Telugu, Hindi, Tamil, and Kannada unicode scripts

## 3. Elevation & Glassmorphism
- **Cards**: `background: rgba(18, 34, 23, 0.75); backdrop-filter: blur(16px); border: 1px solid rgba(34, 197, 94, 0.15);`
- **Border Radius**: `16px` for cards, `9999px` for pills/badges, `12px` for buttons
- **Box Shadow**: `0 10px 30px -10px rgba(0, 0, 0, 0.5), 0 0 20px rgba(34, 197, 94, 0.08)`

## 4. Layout & Responsive Guidelines
- **Mobile First**: Optimized for viewports 375px to 430px with fixed bottom tab bar.
- **Desktop/Tablet Expansion**: Multi-column grid layout for wide screens.
